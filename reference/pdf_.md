# Title

Title

## Usage

``` r
pdf_(expr, title, width = 8, height = 5, file, dir, open = T, ...)
```

## Arguments

- expr:

  plot or expression to draw

- title:

  title stored in the file (defaults to the file name)

- width:

  width in inches

- height:

  height in inches

- file:

  file name (temporary file if not given)

- dir:

  (optional) folder name, if easier to give separately from the file

- open:

  open the file after writing (macOS only)

- ...:

  additional arguments for the graphics device
