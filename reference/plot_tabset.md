# Plot the markdown code for individual tabsets

Plot the markdown code for individual tabsets

## Usage

``` r
plot_tabset(.x, .pf, header = c("## ", " {-}"), options = "warning=FALSE")
```

## Arguments

- .x:

  verctor to iterate through for each tabset panel

- .pf:

  plotting function

- header:

  text to add before and after .x as header

- options:

  options to add before plotting function
