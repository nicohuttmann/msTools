## Usage

``` r
add_n_above(cutoff = 0, position = "max", size = 3, vjust = -0.6, dodge = 0.75)
```

## Arguments

- cutoff:

  value below/above which the label is placed

- position:

  where to place the label ("max", "min" or "mean")

- size:

  text size of the label

- vjust:

  vertical justification of the label

- dodge:

  width passed to `position_dodge()`, to match a dodged geom
